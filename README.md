# 🚀 بوت رادار الصفقات الرقمية المعتمدة (TMO Scalper & Hull Suite Radar Bot)

بوت تداول واستشعار خوارزمي متقدم لمنصة **باينانس (Binance)**، يفحص **أكثر من 300 زوج USDT** على الفريم اليومي (`1D`).  
مبني حصرياً على **أقوى نموذجين تم اختبارهما بالباكتيست التاريخي على 200 عملة رقمية** لتحقيق هدف ربح سريع **+3.0%** (خلال أول يومين) مع تتبع أهداف الموجه الصاعدة **+6.0%**.

---

## 🎯 النموذجان المعتمدان حصرياً في البوت:

### 🌟 1. النموذج الأقوى 🔥 (`TMO + Hull Suite Golden`)
> **شروط الدخول:**
> 1. ارتكاز السعر على منطقة **دعم فني قوية** (قاع سابق Swing Low، أو خط Hull Suite المائل، أو متوسط EMA50/200).
> 2. خط مؤشر **Hull Suite (HMA 55) باللون الأخضر** (اتجاه صاعد وقوة شرائية).
> 3. تقاطع إيجابي لمؤشر الزخم **TMO Scalper** (مؤشر ترو مومنتوم لموبيوس: Mobius True Momentum Oscillator).
> 4. شمعة الإشارة **خضراء صاعدة** (`Close > Open`).
> 5. سيولة فوليوم مرتفعة أعلى من المعدل الطبيعي بنسبة **`≥ 1.15x`** (`Volume >= Volume MA20 * 1.15`).

* **نتائج الباكتيست الموثقة (200 عملة باينانس - هدف 3%):**
  - **الصعود 3%+ خلال أول يومين:** **70.7%** 🔥 (منها **63.3% في نفس يوم الدخول مباشرة 🚀**).
  - **إجمالي من حقق هدف 3%:** **90.9%** 🏆 (فشل 9.1% فقط).
  - **عندما يكون البيتكوين صاعداً (`BTC > EMA50`):**
    - تقفز نسبة الصعود 3%+ في أول يومين إلى **73.8%**.
    - إجمالي تحقيق الهدف: **91.1%**.

---

### ⚡ 2. النموذج الأساسي (`TMO + Hull Suite Base`)
> **شروط الدخول:**
> 1. ارتكاز السعر على **منطقة دعم رئيسية** (Swing Low أو خط Hull Suite أو EMA50/200).
> 2. خط مؤشر **Hull Suite أخضر**.
> 3. تقاطع إيجابي لمؤشر **TMO Scalper**.

* **نتائج الباكتيست الموثقة (200 عملة باينانس - هدف 3%):**
  - **الصعود 3%+ خلال أول يومين:** **63.5%** (منها **50.7% في نفس يوم الدخول مباشرة**).
  - **إجمالي من حقق هدف 3%:** **86.3%**.
  - **عندما يكون البيتكوين صاعداً (`BTC > EMA50`):**
    - تقفز نسبة الصعود 3%+ في أول يومين إلى **65.5%**.
    - يرتفع إجمالي تحقيق الهدف إلى **88.1%** مع معامل ربح **`PF 1.34`** وصافي أرباح تاريخي **`+483.5%`**.

## 📊 رادار وضع البيتكوين (BTC Macro Regime)

أثبتت نتائج الباكتيست أن صفقات العملات البديلة وقت هبوط البيتكوين أسفل متوسط `Daily EMA50` تكون معرضة لضغوط بيعية مفاجئة، لذلك **يقوم البوت في كل تنبيه وكل تقرير بتوضيح الآتي:**
1. **تحديد نوع النموذج بوضوح تام:** هل هي إشارة **🌟 النموذج الأقوى 🔥** أم **⚡ النموذج الأساسي**.
2. **عرض حالة البيتكوين اللحظية:**
   - 🟢 **آمن وصاعد فوق Daily EMA50:** بيئة تداول ممتازة بأعلى معامل ربح تاريخي (`PF 1.34`).
   - 🔴 **حذر وتصحيحي أسفل Daily EMA50:** يوصى بالاكتفاء بالهدف السريع `+3.0%` فوراً والالتزام الصارم بالوقف.

## 📱 أوامر البوت على تليجرام:

| الأمر | الوظيفة |
|---|---|
| `فحص` أو `/scan` | تشغيل فحص فوري شامل لكل الـ 300 عملة وإرسال تقرير الصفقات المطابقة مع تحديد النموذج ووضع البيتكوين |
| `رادار` أو `/radar` | عرض حالة اتجاه البيتكوين والمسار العام للسوق ومسافته عن Daily EMA50 |
| `اتصال` أو `/ping` | اختبار سرعة واتصال البوت المباشر بسيرفرات باينانس |
| `/start` | عرض رسالة الترحيب وشرح النماذج ونسب نجاحها والأوامر المتاحة |

## ⚙️ طريقة التثبيت والتشغيل:

### 1. الإعداد الأولي:
```bash
# تثبيت المكتبات المطلوبة
pip install -r requirements.txt
```

### 2. إعداد المتغيرات (`.env`):
قم بنسخ ملف `.env.example` إلى `.env` وأضف بياناتك:
```env
TELEGRAM_BOT_TOKEN="توكن_بوت_تليجرام_الخاص_بك"
TELEGRAM_CHAT_ID="معرف_شات_تليجرام_الخاص_بك"
BINANCE_API_KEY=""
BINANCE_API_SECRET=""
DRY_RUN=False
```

### 3. التشغيل:
```bash
python bot.py
```

2. **تشغيل GitHub Actions:**
   - يحتوي مجلد `.github/workflows/` على مهام مجدولة لفحص السوق وإرسال التنبيهات يومياً بشكل آلي.
