مبني حصرياً على **أقوى 5 نماذج استراتيجية تم التحقق منها باختبارات الباكتيست على 200 عملة رقمية**، مع تزويده بـ **محرك الصيد اللحظي التلقائي كل ساعة (Hourly Real-Time Scanner)** لمنع تفويت انفجارات السيولة منتصف اليوم، ونظام كتم التكرار الذكي (**Anti-Spam Cache**).

## ⏰ محرك الفحص الساعي الذكي (Hourly Scanner & Anti-Spam Engine)

1. **الرصد اللحظي للسيولة:**
   - يتم تشغيل فحص آلي كل **60 دقيقة** عبر الخلفية أو مجدول المهام (`run_hourly.py`).
   - يلتقط العملات التي انفجرت فيها السيولة في فترات نشاط السوق العالمية (مثل جلسة لندن ونيويورك).
2. **منع الإزعاج والتكرار (Anti-Spam Deduplication):**
   - يحتفظ البوت بملف كاش محلي `alerts_sent_cache.json` لتسجيل الصفقات المرسلة خلال اليوم.
   - يرسل تنبيهاً **فقط للعملات الجديدة** التي اشتعلت فيها السيولة لأول مرة.
   - في حال عدم وجود فرص جديدة، يظل البوت صامتاً تماماً دون إرسال رسائل مكررة.

## 📱 أوامر البوت على تليجرام:

| الأمر | الوظيفة |
|---|---|
| `ساعة` أو `/hourly` | تشغيل فحص الصيد اللحظي الفوري للفرص الجديدة فقط التي دخلتها السيولة حديثاً |
| `فحص` أو `/scan` | فحص شامل لكل العملات وعرض كافة الفرص الحالية مرتبة من الأقوى للأضعف |
| `رادار` أو `/radar` | عرض حالة اتجاه البيتكوين والمسار العام للسوق ومسافته عن Daily EMA50 |
| `اتصال` أو `/ping` | اختبار سرعة اتصال البوت المباشر بسيرفرات باينانس |
| `/start` | عرض دليل الاستخدام والنماذج والنتائج الإحصائية |

## ⚙️ طريقة التثبيت والتشغيل:

